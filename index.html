Installation

Requirements: Python 3.11+, yt-dlp, ffmpeg (recommended), and a Nerd Font.

git clone https://github.com/TheAnonymousCrusher/yt-nerddl.git
cd yt-nerddl
chmod +x yt-nerddl.py
sudo mv yt-nerddl.py /usr/local/bin/yt-nerddl

1. Install Python 3.11+ and ensure FFmpeg is in your PATH.

git clone https://github.com/TheAnonymousCrusher/yt-nerddl.git
cd yt-nerddl
pip install -r requirements.txt
python yt-nerddl.py [options] <url>

*Use Windows Terminal + Nerd Font for proper icon rendering.

Not Recommended: Older versions may appear in AUR.

yay -S yt-nerddl

Usage

yt-nerddl [options] <url>

Options

Option Description
-a, --audioDownload audio only (MP3)
--videoForce video mode
-q, --qualityInteractive quality selector
-H, --highDownload highest available quality
-c, --cookies <browser>Use browser cookies for age-restricted content
-o, --output <dir>Specify output directory
-y, --yesSkip prompts/menus (use defaults/config)
--theme <name>Theme override for this run
-U, --updateUpdate script from GitHub

Configuration

yt-nerddl auto-creates a config on first run at ~/.config/yt-nerddl/config.toml (Linux) or %APPDATA%\yt-nerddl\config.toml (Windows).

[ui]
progress_bar_width = 30
progress_fill = "▰"
progress_empty = "▱"

Downloading Age-Restricted & Private Content

YouTube restricts access to certain videos (18+ content, unlisted videos, members-only). Since yt-nerddl downloads anonymously by default, it cannot access these. Use the -c flag to extract session cookies directly from your web browser.

Troubleshooting

"Database is locked"

Happens if your browser is currently running and actively writing to its cookie database. Fix: Close the browser completely and run again.

"Sign in to confirm your age"

Ensure you specified the exact browser where you are logged in, and that your account can watch the video normally inside that browser.
